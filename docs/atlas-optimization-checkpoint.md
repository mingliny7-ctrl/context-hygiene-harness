## 启动问题根因

Windows `netsh interface ipv4 show excludedportrange protocol=tcp` 包含 4108–4207；原端口 4173 在此范围。uvicorn 日志出现 `[winerror 10013]`，应用导入和初始化成功后绑定失败。旧错误分类大小写敏感，因而只提示“进程异常退出（代码 3）”。

修复服务配置、桌面 URL、Worker、扩展权限及手动脚本为 14173，并对错误标记作不区分大小写匹配。Python 桌面 URL 直接复用服务配置。既有快捷方式不含端口，Native Host 动态加载项目源码，无需重建或重新注册。

## 用户检查

1. 双击原桌面 Conversation Atlas；应打开 <http://127.0.0.1:14173/>。
2. 重载原 Bridge 扩展至 1.0.7；检查“打开图谱”访问同一地址，“启动/关闭服务”仍独立控制 Collector。
3. 展开 GPT账号协作方案，打开主题及关键回答，再返回首页；确认粒子、动画和阅读效果。
4. 当前验收不需要点击“分析新增内容”，不会产生新的付费请求。
