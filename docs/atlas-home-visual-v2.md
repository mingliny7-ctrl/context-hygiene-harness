# Atlas 首页星图 V2

基线 `94189ff`。仅升级首页表现，不修改后端、DeepSeek、SQLite、索引、主题阅读或采集链。

- 首页 Conversation 复用中央主星球的现有 ParticleField 球壳渲染，使用 140 点简化粒子球；不新增 Canvas 或动画循环。
- 每个星球的外部轻标签提供单行标题、省略号和完整原名 tooltip / aria-label。标题不写入球心，不修改真实 Conversation 名称。
- 最近保存事件的排序与六节点上限不变。采用固定错落位置和边界约束，不使用每帧随机布局。
- 首页曲线从星球外缘引出，每条有确定性不同曲率；细线低透明度呼吸，鼠标悬停或键盘聚焦仅增强对应连线。
- 粒子和按钮仍沿原布局过渡，点击仍到统一左中锚点，右侧展开主题；不重写 choose/returnToAtlas。
- 新 CSS 动效遵循原暂停按钮和 prefers-reduced-motion。低强度呼吸代替额外流光粒子，避免抢占主球与标签。
