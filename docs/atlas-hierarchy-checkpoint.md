# Atlas 星球、主题与概念导航验收断点

起点：`8c3b309`，分支 `feat/conversation-atlas-prototype`。

## 本轮实现

- 对话星球自身代表 Conversation，聚焦后直接连接主题，不再重复显示矩形对话节点。保留粒子、曲线、左到右展开和最近六颗首页星球。
- 主题已有真实 `subtopics` 时，右侧展开概念节点；概念详情进入属于自身的关键 Assistant 回答，再从 Store 读取完整原文。简单主题直接阅读，不制造概念数据。
- 星球下方和工具栏提供“隐藏 / 删除”；复用既有永久删除、二次确认和禁止重新采集标记。主题详情顶部提供“移除主题”，语义为可恢复隐藏，不删除原文或索引覆盖。“已隐藏”统一恢复对话和主题。
- 尚无概念的主题提供“细分为概念”：先读取单主题预算，用户明确确认才发送一次模型请求。结果验证来源、角色、顺序和完整覆盖后，更新原 Segment 的 `analysis_json.subtopics` 与本地回执；不改变 Segment ID、标题、原文、覆盖和已有分析缓存。
- 概念是单层语义导航。每次模型输出最多八块，单一概念允许不拆；多批增量可以累计超过八块。未实现无限递归树，也不宣称机器输出已经人工验收为原子概念。

## 数据和调用边界

复用 `atlas_segments`、B4 覆盖表、现有 DeepSeek Client、任务及调用记录。新增派生表只有 `atlas_segment_visibility(conversation_id, segment_id, hidden_at)`，复合主键保证重复隐藏幂等。首次管理写入前自动备份旧派生库；启动和只读页面不迁移。

主题细分和原有新增分析共享数据库执行锁；永久删除也取得同一锁，避免删除与分析竞争。成功细分按来源内容指纹复用，重启后不再调用。失败不污染原主题，记录失败后由用户决定是否重试；若请求已发送而进程退出，无法保证供应商未计费，不能宣称跨崩溃请求恰好一次。

概念摘要和本地调用回执不发送给后续增量模型；完整旧概念仅在本地保留并合并。空新增字段不影响历史批次结果指纹。共享同一回答的不同概念获得不同且可重放的 ID。

## 本轮证据

- Python 定向回归：107 项通过（概念细分、主题管理、增量持久化、语义索引、管理/API、Module 5 缓存和 revision）；仅既有 Starlette 弃用警告。
- Atlas 前端：37 项通过，覆盖布局、同源概念引用、粒子、轮询、原文安全渲染和数据读取；入口脚本语法检查通过。
- 正式页面 `http://127.0.0.1:14173/`：真实对话星球直接连接主题；管理入口可见；预算弹窗打开并取消；关键回答正确打开 User/Assistant 原文；返回主题保留选择。当前窄视口使用既有详情浮层，无页面横向溢出；控制台无错误。
- 独立测试库 `14174`：确定性 Provider 创建两个概念，仅用于交互测试；概念节点、返回主题、关键回答到原文、移除主题、刷新保留隐藏状态和恢复后节点完整均通过。未以模拟内容冒充真实语义结果。验证完成后关闭临时页面及服务。
- 本轮未操作用户真实对话的隐藏或删除；永久删除一致性、并发阻止和清理范围使用独立数据库测试。
- 正式 Atlas 重启前后：837 条原文、42 条索引覆盖、11 个主题、6 条历史模型调用；身份/角色/正文排序摘要保持一致。本轮新增真实模型请求为 **0**。Collector 仍在 18000，未修改 Reader、Bridge、Native Host。
- 页面验证使用 Windows 上的内置浏览器；当前没有可接管的 Edge 窗口，未将此声明为原生 Edge 验收。

## 操作与剩余验收

1. 打开正式页面，选择对话星球，确认星球与主题之间没有多余对话卡片。
2. 星球下方“隐藏 / 删除”管理整段对话；主题详情顶部“移除主题”可从图谱隐藏，再从“已隐藏”恢复。
3. 当前真实十一主题均无历史概念数据。选择主题后点击“细分为概念”，检查预算并确认才会付费；有结果后展开概念，进入关键回答和原文。

真实语义质量仍待首次付费样本验证，未自行调用。已读取的候选单主题预算：2 条消息，最多 1 次 `deepseek-v4-pro` 请求，输入保守上界 13,305 Token、输出上限 4,096 Token，不预留自动修复请求。用户确认后才执行；若来源或配置变化，以新的预览预算为准。

本轮没有增加收藏推荐、跨对话关联、第三服务或自动分析调度。
